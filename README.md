One original one-line comedy joke for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on make.fun — the excuse a robot vacuum gives after eating a sock, told as a police interrogation: four hours, zero words, one eaten piece of evidence.

> I gave the sock four hours to talk. It said nothing, so I ate the evidence. Case closed.

## How it works

`main.py` (Python 3.13 stdlib only, no dependencies, no network) writes the joke to `/output/entry.txt`, falling back to `./output/entry.txt` when `/output` is not writable. The text is validated before writing: 1–200 characters, a single line, not only whitespace. The program is deterministic: every run writes the same 88 characters.

## Run it

```sh
python3 main.py
```
